# Игра «Крестики-нолики» на Java

## 1. Полный код

``` java
import java.util.Scanner;

void main() {
    Player player1 = new Player("Кирилл", 'X');
    Player player2 = new Player("Влентин", 'O');

    char[][] board = createBoard();
    printBoard(board);

    Player[] players = {player1, player2};

    int moves = 0;

    while (true) {
        printBoard(board);
        Player player = players[moves % 2];
        int cell = readCell(player.name);

        if (!makeMove(board, cell, player.symbol)) {
            System.out.println("Клетка занята!");
            continue;
        }

        moves++;

        if (checkWin(board, player.symbol)) {
            System.out.println("Выйграл " + player.name);
            player.addWin();
            break;
        }

        if (moves == 9) {
            System.out.println("Ничья!");
            break;
        }
    }

    System.out.println("Игрок " + player1.name + " Побед: " + player1.wins);
    System.out.println("Игрок " + player2.name + " Побед: " + player2.wins);
    printBoard(board);
}

char[][] createBoard() {
    char[][] board = new char[3][3];
    char num = '1';
    for (int i = 0; i < 3; i++) {
        for (int k = 0; k < 3; k++) {
            board[i][k] = num;
            num += 1;
        }
    }
    return board;
}

void printBoard(char[][] board) {
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[i].length; j++) {
            System.out.print(board[i][j] + " ");
        }
        System.out.println();
    }
    System.out.println();
}

boolean checkWin(char[][] board, char player) {
    for (int i = 0; i < 3; i++) {
        if (board[i][0] == player && board[i][1] == player && board[i][2] == player) {
            return true;
        }
        if (board[0][i] == player && board[1][i] == player && board[2][i] == player) {
            return true;
        }
    }

    if (board[0][0] == player && board[1][1] == player && board[2][2] == player) {
        return true;
    }
    if (board[0][2] == player && board[1][1] == player && board[2][0] == player) {
        return true;
    }

    return false;
}

boolean makeMove(char[][] board, int cell, char player) {
    int row = (cell - 1) / 3;
    int col = (cell - 1) % 3;

    if (board[row][col] == 'X' || board[row][col] == 'O') {
        return false;
    }

    board[row][col] = player;
    return true;
}

int readCell(String player_symbol) {
    Scanner scanner = new Scanner(System.in);
    int cell;
    do {
        System.out.println("Ходят: " + player_symbol);
        System.out.println("Введите номер клетки от 1 до 9:");
        cell = scanner.nextInt();
    } while (cell < 1 || cell > 9);
    return cell;
}


class Player {
    // Поля
    String name;
    char symbol;
    int wins;

    Player(String name, char symbol) {
        this.name = name;
        this.symbol = symbol;
        this.wins = 0;
    }

    void addWin() {
        this.wins++;
    }
}
```

## 2. Разбор программы для повторения

### 2.1. Подключение Scanner

``` java
import java.util.Scanner;
```

- `import java.util.Scanner;` подключает готовый инструмент Java, который умеет читать то, что человек вводит с
  клавиатуры в консоль

### 2.2. Начинаем игру и создаём игроков

``` java
void main() {
    Player player1 = new Player("Кирилл", 'X');
    Player player2 = new Player("Валентин", 'O');

    char[][] board = createBoard();
    printBoard(board);

    Player[] players = {player1, player2};

    int moves = 0;
```

- `main()` - специальный метод, с которого Java начинает запускать нашу программу
- `new Player("Кирилл", 'X')` создаёт первого игрока с именем «Кирилл» и символом `X`, которым игрок будет ходить
- `new Player("Валентин", 'O')` создаёт второго игрок с именем «Валентин» и с символом `O`
- `char[][] board` - переменная, в которой будет храниться игровое поле. Два знака `[][]` означают, что это двумерный
  массив, который нам проще представлять, как таблицу: в ней есть строки и столбцы
- `createBoard()` создаёт пустое игровое поле и расставляет в клетках номера от 1 до 9
- `printBoard(board)` показывает поле на экране
- `Player[] players` - список из двух игроков. Он пригодится, чтобы по очереди давать им ходить
- `int moves = 0` - счётчик ходов. Пока никто не походил, поэтому он равен нулю

### 2.3. Организация ходов игроков

``` java
while (true) {
    printBoard(board);
    Player player = players[moves % 2];
    int cell = readCell(player.name);

    if (!makeMove(board, cell, player.symbol)) {
        System.out.println("Клетка занята!");
        continue;
    }

    moves++;

    if (checkWin(board, player.symbol)) {
        System.out.println("Выиграл " + player.name);
        player.addWin();
        break;
    }

    if (moves == 9) {
        System.out.println("Ничья!");
        break;
    }
}
```

Это главная часть игры: здесь игроки ходят по очереди, а программа проверяет, кто победил и закончилась ли игра ничьей.

- `while (true)` запускает повторение команд. Цикл будет работать снова и снова (бесконечно), пока мы не остановим его
  изнутри (с помощью оператора `break`)
- `printBoard(board)` показывает поле перед очередным ходом
- `players[moves % 2]` выбирает игрока, которому сейчас нужно ходить

_Как работает `moves % 2`?_

Знак `%` находит остаток от деления:

- если `moves` равно `0`, `2`, `4`, `8` и так далее, остаток будет `0` - ходит первый игрок
- если `moves` равно `1`, `3`, `5`, `7`, `9` и так далее, остаток будет `1` - ходит второй игрок

Получается, что игроки автоматически меняются после каждого успешного хода

- `readCell(player.name)` просит игрока выбрать клетку и получает её номер
- `makeMove(...)` пытается поставить в выбранную клетку символ игрока
- `if` проверяет условие. Если `makeMove()` вернул `false`, значит клетка уже занята
- `System.out.println("Клетка занята!")` сообщает об ошибке
- `continue` пропускает оставшиеся команды цикла и начинает новый круг. Игрок при этом не меняется, потому что ход не
  был засчитан
- `moves++` увеличивает счётчик ходов на один. Эта команда выполняется только после успешного хода
- `checkWin(...)` проверяет, получилось ли у игрока собрать три одинаковых символа в ряд
- Если метод вернул `true`, программа сообщает имя победителя
- `player.addWin()` добавляет победителю одну победу в его счёт
- `break` останавливает игровой цикл
- Если счётчик дошёл до `9`, значит все клетки заняты. Если до этого никто не победил, программа объявляет ничью

### 2.4. Вывод результатов

System.out.println("Игрок " + player2.name + " Побед: " + player2.wins);

## 3. Разбор методов

Метод - это отдельный набор команд, который выполняет определённую задачу. Например, один метод рисует поле, другой
проверяет победу. Благодаря методам не нужно писать весь код игры в одном большом блоке.

### 3.1. Метод createBoard () - создание поле

``` java
char[][] createBoard() {
    char[][] board = new char[3][3];
    char num = '1';
    for (int i = 0; i < 3; i++) {
        for (int k = 0; k < 3; k++) {
            board[i][k] = num;
            num += 1;
        }
    }
    return board;
}
```

**Что делает метод:** создаёт таблицу (двумерный массив) 3 x 3 и записывает в неё номера клеток

Представим, что мы рисуем таблицу на листе бумаги. Нам нужно заполнить её числами по порядку:

``` text
1 2 3
4 5 6
7 8 9
```

**Разбор команд:**

- `char[][] createBoard()` - объявление метода. Его имя `createBoard`, а результатом будет двемерный массив символов.
- `new char[3][3]` создаёт таблицу из трёх строк и трёх столбцов
- `char num = '1'` создаёт переменную с первым номером клетки. Здесь используются одинарные кавычки, потому что `char`
  хранит один символ
- Первый `for` перебирает строки таблицы
- Второй `for` перебирает клетки внутри каждой строки
- `board[i][k] = num` записывает номер в нужную клетку
- `num += 1` переходит к следующему символу: после `'1'` будет `'2'`, затем `'3'` и так далее
- `return board` отдаёт готовую таблицу туда, откуда вызвали метод

### 3.2. Метод printBoard () - вывод поля в консоль

``` java
void printBoard(char[][] board) {
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[i].length; j++) {
            System.out.print(board[i][j] + " ");
        }
        System.out.println();
    }
    System.out.println();
}
```

**Что делает метод:** выводит игровое поле в консоль

- `printBoard` - имя метода. Его можно перевести как «напечатать поле»
- В скобках указан `board` - поле, которое нужно показать
- `void` означает, что метод ничего не возвращает. Он просто выполняет команды
- `board.length` - количество строк в таблице
- `board[i].length` - количество клеток в выбранной строке
- Внешний `for` выбирает строку, а внутренний `for` проходит по клеткам этой строки
- `System.out.print()` выводит символ и оставляет курсор на той же строке, т.е. следующий выведенный символ будет на той
  же строке в консоли, а не на новой
- `System.out.println()` переводит курсор на следующую строку
- Последний `println()` оставляет пустую строку, чтобы поле не сливалось с остальным текстом (например, с сообщениями
  для игроков и от них)

### 3.3. Метод checkWin () - проверка победы

``` java
boolean checkWin(char[][] board, char player) {
    for (int i = 0; i < 3; i++) {
        if (board[i][0] == player && board[i][1] == player && board[i][2] == player) {
            return true;
        }
        if (board[0][i] == player && board[1][i] == player && board[2][i] == player) {
            return true;
        }
    }

    if (board[0][0] == player && board[1][1] == player && board[2][2] == player) {
        return true;
    }
    if (board[0][2] == player && board[1][1] == player && board[2][0] == player) {
        return true;
    }

    return false;
}
```

**Что делает метод:** проверяет, собрал ли игрок три своих символа в одну линию

В крестиках-ноликах победить можно несколькими способами:

- заполнить одну из трёх горизонтальных линий
- заполнить один из трёх вертикальных столбцов
- заполнить диагональ из левого верхнего угла в правый нижний
- заполнить диагональ из правого верхнего угла в левый нижний

Например, если игрок играет за `X`, одна из выигрышных ситуаций выглядит так:

``` text
X X X
O 5 O
7 8 9
```

Разберём код:

- `boolean` означает, что метод отвечает на вопрос: да или нет. В Java это значения `true` и `false`
- `board` - игровое поле, а `player` - символ игрока, победу которого проверяем
- Цикл `for` перебирает все три строки и столбца
    - Первое условие проверяет три клетки одной строки
    - Второе условие проверяет три клетки одного столбца
    - `&&` означает «И». Все три части условия должны быть верными одновременно
- Следующие два `if` проверяют две диагонали
- Если найдена линия из трёх символов игрока, `return true` сообщает, что игрок победил
- Если ни одна линия не подошла, `return false` сообщает, что победной комбинации пока нет

### 3.4. Метод makeMove () - совершение хода

``` java
boolean makeMove(char[][] board, int cell, char player) {
    int row = (cell - 1) / 3;
    int col = (cell - 1) % 3;

    if (board[row][col] == 'X' || board[row][col] == 'O') {
        return false;
    }

    board[row][col] = player;
    return true;
}
```

**Что делает метод:** ставит крестик или нолик в выбранную клетку, если она свободна

Метод получает три вещи:

- `board` - игровое поле
- `cell` - номер клетки, которую выбрал игрок
- `player` - символ игрока (`X` или `O`)

Сначала нужно понять, как найти нужную клетку в таблице. Пользователь выбирает числа от 1 до 9, а Java обращается к
клеткам по номерам от 0 до 2 внутри каждой строки

Например:

- клетка `1` находится в строке `0`, столбце `0`
- клетка `2`находится в строке `0`, столбце `1`
- клетка `4` находится в строке `1`, столбце `0`
- клетка `9` находится в строке `2`, столбце `2`.

Для этого используются две формулы:

- `row = (cell - 1) / 3` вычисляет номер строки. Используеся деление числа нацело - `/`
- `col = (cell - 1) % 3` вычисляет номер столбца. Используеся остаток деления числа - `%`

Почему сначала вычитаем единицу? Потому что пользователь начинает нумерацию с 1, а Java - с 0

Дальше программа проверяет клетку:

- `==` сравнивает два значения: равны ли они
- `||` означает «ИЛИ». Достаточно, чтобы в клетке был `X` или `O`, чтобы считать её занятой
- Если клетка занята, `return false` сообщает, что поставить символ не получилось
- Если клетка свободна, команда `board[row][col] = player` записывает туда символ игрока
- `return true` сообщает, что ход прошёл успешно

### 3.5. Метод readCell () - запрос номера клетки

``` java
int readCell(String player_symbol) {
    Scanner scanner = new Scanner(System.in);
    int cell;
    do {
        System.out.println("Ходят: " + player_symbol);
        System.out.println("Введите номер клетки от 1 до 9:");
        cell = scanner.nextInt();
    } while (cell < 1 || cell > 9);
    return cell;
}
```

**Что делает метод:** спрашивает у игрока номер клетки и возвращает введённое число

- `int` означает, что метод вернёт целое число
- `player_symbol` - имя игрока, который сейчас ходит (несмотря на название переменной, в неё передаётся именно имя)
- `Scanner scanner = new Scanner(System.in)` создаёт инструмент для чтения того, что пользователь вводит с клавиатуры
- `int cell` - переменная, в которой будет храниться номер выбранной клетки
- `do-while` - цикл, который сначала выполняет команды, а потом проверяет условие. Поэтому вопрос будет задан хотя бы
  один раз
- `System.out.println()` показывает сообщение на экране
- `scanner.nextInt()` считывает целое число, которое ввёл игрок
- `cell < 1 || cell > 9` проверяет, не ввёл ли игрок число меньше 1 или больше 9.
- Если число не подходит, цикл задаёт вопрос ещё раз
- `return cell` возвращает выбранный номер в то место программы, откуда вызвали метод

### 3.6. Класс Player - описание игрока

``` java
class Player {
    String name;
    char symbol;
    int wins;

    Player(String name, char symbol) {
        this.name = name;
        this.symbol = symbol;
        this.wins = 0;
    }

    void addWin() {
        this.wins++;
    }
}
```

**Что делает класс:** хранит информацию об игроке. Можно представить его как анкету, по которой создаётся каждый
участник игры

У каждого игрока есть три характеристики - поля класса:

- `String name` - имя игрока. Например, «Кирилл».
- `char symbol` - его символ. Например, `X`.
- `int wins` - количество побед. В начале игры оно равно нулю.

**Конструктор Player**

``` java
Player(String name, char symbol) {
    this.name = name;
    this.symbol = symbol;
    this.wins = 0;
}
```

Конструктор - специальная часть класса, которая помогает создать и настроить нового игрока

- `Player(...)` называется так же, как класс
- `name` и `symbol` - значения, которые мы передаём при создании игрока
- `this.name = name` записывает имя в карточку нового игрока
- `this.symbol = symbol` записывает его игровой символ
- `this.wins = 0` устанавливает начальное количество побед

Слово `this` означает «этот объект». Например, `this.name` - имя именно того игрока, которого мы сейчас создаёмю

**Метод addWin ()**

``` java
void addWin() {
    this.wins++;
}
```

Этот метод вызывается, когда игрок выигрывает партию

- `void` означает, что метод ничего не возвращает
- `this.wins++` увеличивает количество побед этого игрока на один.
- Например, если у игрока было 2 победы, после выполнения команды станет 3

## 4. Как проходит одна игра

1. Программа создаёт двух игроков: одного с крестиками, другого с ноликами
2. Создаёт игровое поле и показывает номера клеток
3. Выбирает игрока, который ходит первым
4. Просит его ввести номер клетки
5. Проверяет, свободна ли эта клетка
6. Если клетка занята, просит игрока выбрать другую
7. Если клетка свободна, ставит туда его символ
8. Проверяет, собрал ли игрок три символа в линию
9. Если да - объявляет победителя и увеличивает его счётчик побед
10. Если все девять клеток заняты, а победителя нет, объявляет ничью
11. Показывает итоговое поле и количество побед каждого игрока
