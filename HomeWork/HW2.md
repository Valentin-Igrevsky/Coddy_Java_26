## ⁉️ Повторение: ввод данных через Scanner

На занятии мы вспомнили, что программа может не только выводить данные на экран, но и **спрашивать** их у пользователя.
Для этого используется специальный помощник - `Scanner`.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Введите число:");
        int number = scanner.nextInt();
        System.out.println("Ты ввёл: " + number);
    }
}
```

**Важно запомнить:**

- Строчка `import java.util.Scanner;` пишется в самом начале файла, до `public class Main`
- `scanner.nextInt()` - считывает **целое** число (тип `int`)
- Перед считыванием стоит написать `System.out.println(...)`, чтобы человек понял, что от него хотят

## ⁉️ Арифметические операции

Так же, как и на обычной математике, в Java есть операции над числами:

| Операция           | Знак | Пример  | Результат |
|--------------------|------|---------|-----------|
| Сложение           | `+`  | `5 + 2` | `7`       |
| Вычитание          | `-`  | `5 - 2` | `3`       |
| Умножение          | `*`  | `5 * 2` | `10`      |
| Деление            | `/`  | `5 / 2` | `2`       |
| Остаток от деления | `%`  | `5 % 2` | `1`       |

**Важно запомнить:** если делить `int` на `int`, Java **отбрасывает** дробную часть результата. Например, `5 / 2` даст
`2`, а не `2.5`! Знак `%` (остаток от деления) как раз помогает узнать, что "потерялось" при делении.

---

## ⁉️ Операции с присваиванием

Часто нужно изменить значение переменной, используя её же текущее значение. Например, прибавить очки к уже
существующему счёту игры. Для этого есть короткая запись:

| Длинная запись        | Короткая запись | Что происходит       |
|-----------------------|-----------------|----------------------|
| `score = score + 10;` | `score += 10;`  | к score прибавили 10 |
| `score = score - 5;`  | `score -= 5;`   | из score вычли 5     |
| `score = score * 2;`  | `score *= 2;`   | score умножили на 2  |
| `score = score + 1;`  | `score++;`      | score увеличили на 1 |
| `score = score - 1;`  | `score--;`      | score уменьшили на 1 |

## 🏁 Пример

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Введите первое число:");
        int a = scanner.nextInt();
        System.out.println("Введите второе число:");
        int b = scanner.nextInt();

        System.out.println("Сумма: " + (a + b));
        System.out.println("Разность: " + (a - b));
        System.out.println("Произведение: " + (a * b));
        System.out.println("Частное: " + (a / b));
        System.out.println("Остаток от деления: " + (a % b));

        int score = 0;
        score += 10;
        System.out.println("Счёт после +10: " + score);
        score *= 2;
        System.out.println("Счёт после умножения на 2: " + score);
        score--;
        System.out.println("Счёт после -1: " + score);
    }
}
```

**Пример вывода в консоль (для a = 7, b = 2):**

```text

7
Введите второе число:
2
Сумма: 9
Разность: 5
Произведение: 14
Частное: 3
Остаток от деления: 1
Счёт после +10: 10
Счёт после умножения на 2: 20
Счёт после -1: 19
```

## ⁉️ Побитовые операции

На занятии мы кратко упомянули, что компьютер хранит числа не так, как привычно людям, а в виде набора нулей и единиц - это называется **двоичная система счисления**.

Из-за этого в Java есть операции, которые работают не со всем числом сразу, а сравнивают его **по битам** (по каждой цифре 0 или 1 отдельно). Для примеров используются числа `5` (`00000101` в двоичном виде) и `3` (`00000011` в двоичном виде):

| Операция        | Знак | Пример в десятичной системе | Пример в двоичной системе | Результат | Результат в двоичной системе |
|-----------------|------|-----------------------------|---------------------------|-----------|------------------------------|
| И               | `&`  | `5 & 3`                     | `00000101 & 00000011`     | `1`       | `00000001`                   |
| ИЛИ             | `\|` | `5 \| 3`                    | `00000101 \| 00000011`    | `7`       | `00000111`                   |
| Исключающее ИЛИ | `^`  | `5 ^ 3`                     | `00000101 ^ 00000011`     | `6`       | `00000110`                   |
| НЕ              | `~`  | `~5`                        | `~00000101`               | `-6`      | `11111010`                   |
| Сдвиг влево     | `<<` | `5 << 1`                    | `00000101 << 1`           | `10`      | `00001010`                   |
| Сдвиг вправо    | `>>` | `5 >> 1`                    | `00000101 >> 1`           | `2`       | `00000010`                   |

Самые простые побитовые операции:

- **`&`** - побитовое **И**. Смотрит на каждую пару битов: если **оба** бита равны `1`, в результате тоже будет `1`,
  иначе — `0`
- **`|`** - побитовое **ИЛИ**. Смотрит на каждую пару битов: если **хотя бы один** из битов равен `1`, в результате
  будет `1`, иначе - `0`

```text
  0101   (5)
& 0011   (3)
------
  0001   (1)  → результат a & b


  0101   (5)
| 0011   (3)
------
  0111   (7)  → результат a | b
```
