## ⁉️ Одномерные массивы

Массив — это как ряд пронумерованных ячеек инвентаря в Minecraft: в нём хранится много значений **одного типа** под
одним именем.

```java
int[] scores = {10, 25, 7, 40, 18};   // создали массив сразу со значениями
int[] health = new int[5];            // создали массив из 5 ячеек, все заполнены нулями
```

**Важно запомнить:**

- Нумерация ячеек (индексы) начинается с **нуля**: первый элемент - `scores[0]`, второй - `scores[1]`
- Длина массива - `scores.length`, а индекс последнего элемента - `scores.length - 1`
- Если обратиться к несуществующей ячейке (например, `scores[5]` в массиве из 5 элементов), программа выдаст ошибку
  `ArrayIndexOutOfBoundsException`

```java
System.out.println(scores[0]);   // 10 — прочитали значение
scores[2] = 99;                  // изменили третий элемент
```

---

## ⁉️ Обход массива: for и for each

Обычный `for` - когда нужен номер элемента (индекс):

```java
for (int i = 0; i < scores.length; i++) {
    System.out.println("Ячейка " + i + ": " + scores[i]);
}
```

`for each` - когда нужны только сами значения. Читается как «для каждого `score` из `scores`»:

```java
for (int score : scores) {
    System.out.println(score);
}
```

---

## 📚 Что-то новое

**Сумма элементов массива:**

```java
int sum = 0;
for (int score : scores) {
    sum += score;
}
```

**Поиск наибольшего элемента в массиве:**

```java
int max = scores[0];
for (int score : scores) {
    if (score > max) {
        max = score;
    }
}
```

## ✅ Основное задание

### Задание 1. Урон по боссу

В игре босс получил 7 ударов. Урон каждого удара записан в массив:

```java
int[] damage = {12, 45, 7, 30, 18, 25, 3};
```

Напиши программу, которая обработает этот массив в два этапа.

**Этап 1. Вывод всех ударов (обычный цикл `for`)**

1. Создай обычный цикл `for`, который перебирает все элементы массива по индексам: от `0` до `damage.length`
2. Внутри цикла выводи каждый удар с его номером, например: `Удар 1: 12`
3. Обрати внимание: у людей счёт ударов начинается с 1, а индексы массива - с 0. Поэтому в подписи выводи `i + 1`,
   а само значение бери из `damage[i]`

**Этап 2. Подсчёт результатов (цикл `for each`)**

1. Создай две переменные типа `int` и обнули их:
    - `totalDamage` - в ней будет накапливаться общий урон
    - `strongHits` - в ней будет считаться, сколько ударов оказалось сильнее 20
2. Создай цикл `for each`, который перебирает все значения массива `damage`
3. Внутри цикла для каждого значения:
    1. Прибавь его к `totalDamage` - так получится сумма всех ударов
    2. С помощью `if` проверь, что значение больше 20. Если да - увеличь `strongHits` на 1
4. **После** цикла (а не внутри него!) выведи в консоль результаты: общий урон и количество ударов сильнее 20
5. Запусти программу и проверь результат

### Задание 2. Игровое поле 5×5

Игровое поле - это таблица из строк и столбцов. Для неё нужен **двумерный массив**. Создайте поле 5 на 5, заполненное
нулями, и расставь в нём числа от 1 до 9.

1. Создай двумерный массив `int[][] mas = new int[5][5];` - Java сама заполнит все 25 ячеек нулями
2. Вручную, обращаясь к ячейкам через `mas[строка][столбец]`, расставь числа от 1 до 9 так, чтобы они образовали
   квадрат 3×3 **в центре** поля:

```text
0 0 0 0 0
0 1 2 3 0
0 4 5 6 0
0 7 8 9 0
0 0 0 0 0
```

3. Выведите результат в консоль. Для этого понадобится следующий код:

```java
for (int i = 0; i < mas.length; i++) {
    for (int j = 0; j < mas[i].length; j++) {
        System.out.print(mas[i][j] + " ");
    }
    System.out.println();
}
```

Программу и результат в консоли нужно сфотографировать и показать преподавателю (можно попросить родителей) или
принести фото с собой, если у вас есть собственный телефон

## 🏁 Пример

**Задание 1:**

```java
public class Main {
    public static void main(String[] args) {
        int[] damage = {12, 45, 7, 30, 18, 25, 3};

        // Этап 1. Вывод всех ударов с номерами
        for (int i = 0; i < damage.length; i++) {
            System.out.println("Удар " + (i + 1) + ": " + damage[i]);
        }

        // Этап 2. Подсчёт общего урона и сильных ударов
        int totalDamage = 0;
        int strongHits = 0;

        for (int d : damage) {
            totalDamage += d;
            if (d > 20) {
                strongHits++;
            }
        }

        System.out.println("Общий урон: " + totalDamage);
        System.out.println("Ударов сильнее 20: " + strongHits);
    }
}
```

**Пример вывода в консоль:**

```text
Удар 1: 12
Удар 2: 45
Удар 3: 7
Удар 4: 30
Удар 5: 18
Удар 6: 25
Удар 7: 3
Общий урон: 140
Ударов сильнее 20: 3
```
