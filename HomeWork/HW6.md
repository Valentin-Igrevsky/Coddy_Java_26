---

## ⁉️ Что такое метод и как его создать

Метод - это именованный блок (кусок/часть) кода, который можно запускать из любого места программы столько раз, сколько нужно. Это как «команда» в игре: один раз придумали, а потом просто вызываем по имени.

```java
static void printGreeting() {
    System.out.println("Добро пожаловать в игру!");
}
```

Здесь:

- `static` - пока просто пишем (зачем он нужен, разберём позже)
- `void` - метод **ничего не возвращает**, он только что-то делает
- `printGreeting` - **имя** метода
- `()` - скобки для параметров (сейчас они пустые)
- `{ }` - тело метода, то, что он выполняет

Чтобы запустить метод, его нужно **вызвать** - написать имя и скобки:

```java
void main(String[] args) {
    printGreeting();
}
```

---

## ⁉️ Параметры метода

Параметры - это «входные данные» метода - то, что мы отдаем методу, чтобы он что-то с этим сделал. Они пишутся в скобках: сначала тип, потом имя. При вызове в скобках передаём конкретные значения:

```java
static void add(int a, int b) {
   System.out.println("Сумма " + a + " и " + b + " равна " + (a+b));
}

add(52, 67);
```

Количество, порядок и типы передаваемых значений должны совпадать с параметрами метода

---

## ⁉️ Метод, который возвращает значение

Если метод должен не просто что-то сделать, а **вычислить и отдать результат**, вместо `void` пишут тип результата, а в конце используют `return`:

```java
static int add(int a, int b) {
   return a + b;
}

int sum = add(52, 67);
System.out.println("Сумма 52 и 67 равна " + sum);
```

## ⁉️ Обход двумерного массива

Для вывода таблицы нужны два вложенных цикла: внешний перебирает строки, внутренний - столбцы в каждой строке.

```java
for (int i = 0; i < board.length; i++) {          // board.length - количество строк
    for (int j = 0; j < board[i].length; j++) {   // board[i].length - количество столбцов
        System.out.print(board[i][j] + " ");      // print - остаёмся на той же строке
    }
    System.out.println();                         // после каждой строки - переход на новую
}
```

## ✅ Основное задание

### Задание 1. Метод printBoard

На занятии мы начали писать «Крестики-нолики» и уже написали метод `createBoard`, который создаёт игровое поле:

```java
static char[][] createBoard() {
    char[][] board = new char[3][3];
    char num = '1';
    for (int i = 0; i < 3; i++) {
        for (int k = 0; k < 3; k++) {
            board[i][k] = num;
            num += 1;
        }
    }
    return board;
}
```

Этот метод создаёт поле 3×3 и заполняет его символами от `'1'` до `'9'` - это номера клеток. Готовое поле метод
**возвращает** (`return board;`), поэтому его результат нужно сохранить в переменную: `char[][] board = createBoard();`

Но пока поле нельзя увидеть - оно есть только в памяти компьютера. Ваша задача: написать метод `printBoard`, который выводит поле в консоль.

1. В методе `main` создай поле: `char[][] board = createBoard();`
2. Ниже `main` создай метод `static void printBoard(char[][] board)`. Он принимает поле как параметр и ничего не возвращает
3. Внутри метода с помощью двух вложенных циклов `for` выведи поле так, чтобы каждая строка массива была на отдельной строке консоли, а символы в строке шли через пробел

💡 **Подсказка:** Пример выполнения есть в разделе памятки `⁉️ Обход двумерного массива`, вам нужно просто правильно объединить описание метода из пунка 2 и кода из памятки.

### Задание 2. Как понять, что игрок победил?

Игра должна уметь определять победителя. Писать код для этого пока **не обязательно** - сначала нужно придумать, как это сделать:

1. Нарисуй на листе бумаги поле 3×3. В каждой клетке подпиши её координаты в массиве: `[строка][столбец]`, например в
   левой верхней клетке - `[0][0]`
2. Выпиши **все** линии, на которых можно выиграть. Подсказка: их ровно 8 - три горизонтальные, три вертикальные и две
   диагональные. Каждую линию запиши тремя парами координат
3. В коде метода `main` из задания 1 допишите проверку (через конструкцию `if`) на то, что игрок `X` выйграл. Достаточно будет написать 3-4 проверки из 8 возможных. 

Результат (записи на листе бумаги и код) нужно сфотографировать и показать преподавателю (можно попросить
родителей) или принести фото с собой, если у вас есть собственный телефон. Ничего страшного если не получится найти все 8 способов выйграть.

## 🏁 Пример

**Задание 1:**

```java
public class Main {
    public static void main(String[] args) {
        char[][] board = createBoard();
        printBoard(board);
    }

    static char[][] createBoard() {
        char[][] board = new char[3][3];
        char num = '1';
        for (int i = 0; i < 3; i++) {
            for (int k = 0; k < 3; k++) {
                board[i][k] = num;
                num += 1;
            }
        }
        return board;
    }

    static void printBoard(char[][] board) {
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[i].length; j++) {
                System.out.print(board[i][j] + " ");
            }
            System.out.println();
        }
        System.out.println();
    }
}
```

**Пример вывода в консоль:**

```text
1 2 3 
4 5 6 
7 8 9 
```
