## ⁉️ Класс и объект

**Класс** - это описание, «чертёж»: какие характеристики и какие действия будут у предметов определённого вида.
**Объект** - это конкретный предмет, созданный по этому чертежу.

Как тип моба в Minecraft и конкретный зомби на карте: тип один, а зомби может быть много, и у каждого своё здоровье.

Из чего состоит класс:

- **поля** - характеристики объекта (здоровье, урон, имя)
- **методы** - действия объекта (получить урон, проверить, жив ли он)

Класс обычно пишется в отдельном файле, название которого совпадает с названием класса. Чтобы создать такой файл в
IntelliJ IDEA, нажми правой кнопкой мыши на папку `src` → **New** → **Java Class**. Названия классов принято писать с
**большой** буквы: `Zombie`, `Player`.

---

## ⁉️ Описание класса: поля и методы

```java
class Zombie {
    int health;     // поле - здоровье
    int damage;     // поле - урон

    void takeDamage(int amount) {   // метод - получить урон
        health -= amount;
    }

    boolean isAlive() {             // метод - проверить, жив ли зомби
        return health > 0;
    }
}
```

**Важно запомнить:**

- Поля пишутся в самом начале класса: сначала тип, потом имя, как обычные переменные
- Внутри методов можно свободно использовать поля того же объекта, например `health`
- Метод может ничего не возвращать (`void`) или возвращать результат (`boolean`, `int` и другие типы) через `return`

---

## ⁉️ Конструктор

Конструктор - особый метод, который запускается в момент создания объекта и задаёт начальные значения полей. У него
есть два отличия от обычных методов: он называется **так же, как класс**, и у него **нет типа результата** (даже
`void` не пишется).

```java
class Zombie {
    int health;
    int damage;

    Zombie(int health, int damage) {
        this.health = health;
        this.damage = damage;
    }
}
```

Слово `this` означает «этот объект». Запись `this.health` - это **поле** объекта, а просто `health` - **параметр**
конструктора с таким же именем. Без `this` Java не поймёт, что мы хотим записать значение в поле.

---

## ⁉️ Создание объектов и вызов методов

Объект создаётся оператором `new`. В скобках передаются аргументы для конструктора. Чтобы обратиться к полю или вызвать
метод объекта, используется точка. В примере ниже используется класс `Zombie` из памяток выше - целиком: с полями,
конструктором и двумя методами.

```java
void main() {
    Zombie z1 = new Zombie(20, 5);
    Zombie z2 = new Zombie(30, 8);

    z1.takeDamage(25);

    System.out.println(z1.health);     // -5
    System.out.println(z1.isAlive());  // false
    System.out.println(z2.health);     // 30 - у второго зомби ничего не изменилось
}
```

Объекты одного класса **независимы** друг от друга: удар по `z1` никак не повлиял на здоровье `z2`.

## ⭐ Задание со звёздочкой

В части 2 основного задания (пункт 3) нужно было вывести в консоль характеристики **каждого** объекта. Если объектов
много, получается много однотипных строк с `System.out.println`, в которых легко ошибиться или что-то забыть. Эту
работу можно упростить двумя способами - а потом объединить их.

**Способ 1. Вывод через цикл `for each`**

1. Положите все созданные объекты в один массив. Тип элементов массива - твой класс (как создавать и перебирать такой
   массив, смотри в разделе «Что-то новое» выше)
2. Переберите массив циклом `for each`
3. Внутри цикла выведите характеристики **одного** объекта, обращаясь к нему через переменную цикла
   Теперь вывод написан только один раз, но работает для всех объектов сразу. Проверьте: добавь в массив ещё один объект -
   он должен сам появиться в выводе, без новых строк с `println`.

**Способ 2. Метод `info()`**

1. Добавьте в свой класс ещё один метод с названием `info()`. Он ничего не возвращает (`void`) и **сам выводит** в
   консоль всю информацию об объекте: его характеристики и результат метода, который возвращает значение
2. Внутри методов объекта поля доступны напрямую, а другой метод этого же класса можно вызвать просто по его названию -
   без точки и имени объекта
3. Замените в `main` длинный вывод на вызов `info()` у каждого объекта
   Теперь, чтобы показать информацию об объекте, достаточно одного короткого вызова метода `info()`.

**Способ 3. Объединить оба способа**

Положите объекты в массив, перебери их циклом `for each` и в теле цикла вызывай `info()` у каждого объекта. В итоге
весь вывод информации о всех объектах в `main` займёт всего несколько строк, а добавление нового объекта потребует
только добавить его в массив.

**Что нужно сделать:** выполните все три шага по очереди (сначала способ 1, затем способ 2, затем объедините их) и убедитесь,
что в консоль каждый раз выводится одна и та же информация о всех объектах.

Код и результат в консоли можно сфотографировать и показать преподавателю вместе с основным заданием
