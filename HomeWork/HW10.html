«Разбор алгоритма»

В разделе будет подробное объяснение двух методов класса Board (isInside и countNeighbors), которые заполняют поле нашего Сапёра числами.

В основном задании вам нужно будет собрать код описанных методов из готовых блоков: перетащить (на телефоне - нажать) фрагменты из «Набора блоков» в нужные слоты, расставив их в правильном порядке и с правильными отступами. Среди блоков есть лишние обманки. Кнопка «Проверить» подсветит верные слоты зелёным, а ошибки и пустые слоты - красным.

i Разбор алгоритма

Сначала разберёмся, как программа находит соседние мины. В коде два метода: isInside проверяет границы поля, а countNeighbors считает мины вокруг каждой клетки.

1. Метод isInside - проверяем, что клетка находится на поле

public boolean isInside(int row, int col) {
    return row >= 0 && row < rows && col >= 0 && col < cols;
}

У каждой клетки есть координаты: row - номер строки, col - номер столбца. Нумерация начинается с нуля. Например, если в поле 5 строк, их номера - от 0 до 4.

Пример: поле размером 5 × 5

  • public boolean означает, что метод доступен из других классов и возвращает ответ «да» или «нет».
  • isInside(row, col) получает координаты клетки, которую нужно проверить.
  • row >= 0 проверяет, что строка не находится выше поля, а row < rows - что она не ниже последней строки.
  • col >= 0 проверяет, что столбец не находится левее поля, а col < cols - что он не правее последнего столбца.
  • && означает «И»: все четыре условия должны быть верными. Если хотя бы одно неверно, координаты находятся за пределами поля.
  • return возвращает результат проверки: true, если клетка внутри поля, и false, если снаружи.

Зачем это нужно? У клеток на краю поля часть соседей находится за его пределами. Нельзя обращаться к таким клеткам: программа может завершиться с ошибкой. Перед проверкой соседа мы сначала убедимся, что его координаты находятся на игровом поле.

2. Метод countNeighbors - считаем мины вокруг каждой клетки

Метод проходит по всему игровому полю. Для каждой клетки он проверяет до восьми соседей, считает найденные мины и записывает число в эту клетку.

  1. Два внешних цикла for 
    for (int r = 0; r < rows; r++) {
    for (int c = 0; c < cols; c++) {
        ...
    }
}

    Переменная r перебирает строки, а c - столбцы. Так программа по очереди выбирает каждую клетку игрового поля. Один цикл отвечает за строки, второй - за столбцы.

    Как циклы обходят поле

    0,00,10,20,30,4 1,01,11,21,31,4 2,02,12,22,32,4
    r = 1Выбрана вторая строка. c = 1В этой строке выбрана вторая клетка. Затем c увеличится и перейдёт к следующему столбцу.

    Сначала внутренний цикл перебирает столбцы одной строки. Когда строка закончилась, внешний цикл переходит к следующей строке.

  2. Счётчик найденных мин 
    int count = 0;

    Создаём переменную count, в которой будем хранить количество мин вокруг текущей клетки. Она каждый раз начинается с нуля, потому что для следующей клетки нужно выполнить новый подсчёт.

  3. Два внутренних цикла for 
    for (int dr = -1; dr <= 1; dr++) {
    for (int dc = -1; dc <= 1; dc++) {
        ...
    }
}

    Переменные dr и dc принимают значения от -1 до 1. Они задают смещение относительно текущей клетки: на одну клетку вверх или вниз, влево или вправо, а также по диагонали. Так мы перебираем все девять позиций вокруг клетки, включая её саму.

    Все 9 позиций: смещения dr и dc

    -1,-1-1,0-1,1 0,-10,00,1 1,-11,01,1
    drСмещение по строкам: вверх / без сдвига / вниз. dcСмещение по столбцам: влево / без сдвига / вправо.

    Каждая пара чисел - одно сочетание значений dr и dc. Восемь позиций - соседи, центральная позиция (0, 0) - сама клетка.

  4. Пропускаем саму клетку 
    if (dr == 0 && dc == 0) {
    continue;
}

    Если оба смещения равны нулю, координаты указывают на текущую клетку, а не на соседа. Команда continue пропускает оставшуюся часть текущего шага цикла и переходит к следующему. Саму клетку считать не нужно.

    Центральную клетку пропускаем

    ↖↑↗ ←×→ ↙↓↘
    dr = 0иdc = 0 continue - пропустить центр Остальные 8 клеток проверяем.
    сосед текущая клетка - пропускаем
  5. Вычисляем координаты соседа 
    int nr = r + dr;
int nc = c + dc;

    Находим строку nr и столбец nc соседней клетки. Например, если dr равно -1, сосед находится на строку выше. Если dc равно 1, сосед находится на столбец правее.

    Пример вычисления координат

    r = 2, c = 3 + dr = -1, dc = 1 → nr = 1, nc = 4
    0,00,10,20,30,4 1,01,11,21,31,4 2,02,12,22,32,4 3,03,13,23,33,4 4,04,14,24,34,4
    Зелёная: текущая клетка (2, 3). Жёлтая: сосед (1, 4). На одну строку выше и на один столбец правее.
  6. Проверяем, что сосед находится внутри поля 
    isInside(nr, nc)

    Вызываем метод isInside(), передавая ему координаты найденного соседа. Он проверяет, не вышли ли мы за границы игрового поля. Это особенно важно для клеток у краёв и в углах поля.

  7. Проверяем, есть ли мина в соседней клетке 
    cells[nr][nc].isMine()

    Обращаемся к соседней клетке и вызываем isMine(). Метод возвращает true, если в клетке есть мина, и false, если её нет. Вместе с проверкой границ это условие выглядит так:

    if (isInside(nr, nc) && cells[nr][nc].isMine()) {
    ...
}

    Оператор && означает «И»: сосед должен находиться внутри поля и содержать мину.

  8. Увеличиваем счётчик 
    count++;

    Если в соседней клетке обнаружена мина, увеличиваем количество найденных мин на единицу. Запись count++ означает то же самое, что count = count + 1.

  9. Сохраняем результат в текущую клетку 
    cells[r][c].setNeighbors(count);

    Когда все соседи проверены, записываем итоговое количество мин в текущую клетку. Метод setNeighbors() сохраняет число в поле neighbors объекта Cell.

i Как программа считает мины вокруг каждой клетки

На поле 5 × 5 спрятано ровно 10 мин. Серые клетки вокруг поля - это область за его границами: программа проверяет координаты соседей, но не обращается к таким клеткам.

✅ Основное задание

В основном здании вам необходимо собрать по частям описанный алгоритм подсчета количества мин для каждой клетки. Для решения задачи у вас есть 2 поля: «Набор блоков» и «Код класса Board»

«Набор блоков» - это все фрагменты кода, из которых нужно собрать два метода: isInside() и countNeighbors(). Выбирайте подходящий фрагмент и переносите его в пустое место в коде класса Board. Некоторые блоки содержат сразу несколько строк, поэтому их нужно размещать целиком. В наборе также есть три лишних блока-обманки - они похожи на правильные команды, но для решения не подходят.

«Код класса Board» - это заготовка класса, в которой уже показано, где должны находиться методы и их части. Ваша задача - заполнить пустые слоты так, чтобы получился правильный код. Сначала соберите проверку границ isInside(), затем метод countNeighbors(), который перебирает клетки поля, проверяет их соседей и записывает количество найденных мин. Обращайте внимание не только на порядок блоков, но и на то, внутри каких циклов и условий они должны располагаться.

Полупрозрачные чёрточки | в начале строк показывают уровень вложенности - они позволят вам понять, какие части кода где располагаются относительно друг друга.

Для проверки решения используйте кнопку «Проверить»: правильно размещённые блоки станут зелёными, неправильные и пустые слоты - красными. В наборе есть лишние блоки-обманки - их использовать не нужно.

Как только все блоки будут размещены верно, результат нужно сфотографировать и показать преподавателю (можно попросить родителей) или принести фото с собой, если у вас есть собственный телефон
