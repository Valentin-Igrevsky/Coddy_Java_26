## ⁉️ Логические выражения

Логическое выражение - это выражение, результат которого всегда `true` или `false`. Такие выражения получаются с помощью
операторов сравнения и логических операторов:

| Оператор | Что означает                       |
|----------|------------------------------------|
| `==`     | равно                              |
| `!=`     | не равно                           |
| `>`      | больше                             |
| `<`      | меньше                             |
| `>=`     | больше или равно                   |
| `<=`     | меньше или равно                   |
| `&&`     | И (оба условия истинны)            |
| `\|\|`   | ИЛИ (хотя бы одно условие истинно) |
| `!`      | НЕ (переворачивает результат)      |

```java
int health = 20;
boolean isLowHealth = health < 30;               // true
boolean isCritical = health > 0 && health < 10;  // false
```

## ⁉️ Условный оператор if / else

Условный оператор позволяет программе выполнять разные действия в зависимости от того, истинно логическое выражение
или нет:

```java
if(условие){
        // выполнится, если условие true
}else{
        // выполнится, если условие false
}
```

Можно проверять несколько условий подряд с помощью `else if`:

```java
if (health >70) {
        System.out.println("Отличное состояние");
} else if (health >30){
        System.out.println("Среднее состояние");
} else {
        System.out.println("Критическое состояние");
}
```

## ⁉️ Конструкция switch / case

Когда нужно сравнить одну переменную с несколькими конкретными значениями, удобнее использовать `switch`, а не
длинную цепочку `if / else if`:

```java
int level = 2;

switch(level) {
    case 1:
        System.out.println("Лёгкий уровень");
        break;
    case 2:
        System.out.println("Средний уровень");
        break;
    case 3:
        System.out.println("Сложный уровень");
        break;
    default:
        System.out.println("Неизвестный уровень");
}
```

**Важно запомнить:** после каждого `case` обязательно нужен `break`, иначе программа "провалится" в следующий `case` и выполнит его код тоже. Если ни один `case` не подошёл - выполнится код в `default`. Однако, если нам нужно выполнить только одну команду внутри кейса, мы можем использовать `->`:


```java
int level = 2;

switch(level) {
    case 1 -> System.out.println("Лёгкий уровень");
    case 2 -> System.out.println("Средний уровень");
    case 3 -> System.out.println("Сложный уровень");
    default -> System.out.println("Неизвестный уровень");
}
```

В таком случае оператор `break` нам не нужен, а кода становиться меньше и более читаемым

## ✅ Основное задание №1

Напиши программу «Проверка перед боем», которая помогает определить, готов ли персонаж к битве.

1. Считай с клавиатуры (через `Scanner`) два целых числа:
    1. **health** - здоровье персонажа (число от 0 до 100)
    2. **level** - выбранный уровень сложности (число от 1 до 3)
2. С помощью **логического выражения** определи и сохрани в переменную типа `boolean` с именем **readyForBattle**,
   готов ли персонаж к бою - условие: здоровье больше 30 **И** уровень не равен 3 (сложный уровень требует больше
   здоровья).
3. С помощью **`if / else`** выведи в консоль:
    - Если `readyForBattle == true` - сообщение `"Персонаж готов к бою!"`
    - Если `readyForBattle == false` - сообщение `"Нужно подлечиться перед боем!"`
4. С помощью **`switch / case`** по переменной **level** выведи название уровня сложности:
    - `1` -> `"Уровень: Лёгкий"`
    - `2` -> `"Уровень: Средний"`
    - `3` -> `"Уровень: Сложный"`
    - любое другое число -> `"Неизвестный уровень"`
5. Запусти программу несколько раз с разными значениями **health** и **level**, чтобы проверить все варианты работы
   программы (например: health = 50, level = 1; health = 10, level = 2; health = 80, level = 3).
6. Программу и результат в консоли (для 2-3 разных проверок) нужно сфотографировать и показать преподавателю (можно
   попросить родителей) или принести фото с собой, если у вас есть собственный телефон

## 🏁 Пример

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Введите здоровье персонажа:");
        int health = scanner.nextInt();
        System.out.println("Введите уровень сложности (1-3):");
        int level = scanner.nextInt();

        boolean readyForBattle = health > 30 && level != 3;

        if (readyForBattle) {
            System.out.println("Персонаж готов к бою!");
        } else {
            System.out.println("Нужно подлечиться перед боем!");
        }

        switch (level) {
            case 1:
                System.out.println("Уровень: Лёгкий");
                break;
            case 2:
                System.out.println("Уровень: Средний");
                break;
            case 3:
                System.out.println("Уровень: Сложный");
                break;
            default:
                System.out.println("Неизвестный уровень");
        }
    }
}
```

**Пример вывода в консоль (для health = 50, level = 1):**

```text
Введите здоровье персонажа:
50
Введите уровень сложности (1-3):
1
Персонаж готов к бою!
Уровень: Лёгкий
```
