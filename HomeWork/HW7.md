## ⁉️ Памятка: метод createBoard

```java
static char[][] createBoard() {
    char[][] board = new char[3][3];
    char num = '1';
    for (int i = 0; i < 3; i++) {
        for (int k = 0; k < 3; k++) {
            board[i][k] = num;
            num += 1;
        }
    }
    return board;
}
```

**Как это работает:**

- Метод не получает параметров, а **возвращает** готовое поле - двумерный массив символов `char[][]`. Поэтому вызывать
  его нужно так, чтобы результат сохранился: `char[][] board = createBoard();`
- `new char[3][3]` - таблица из 3 строк и 3 столбцов
- Символы хранятся в компьютере как числа, поэтому к символу можно прибавлять число: `'1'` + 1 даёт `'2'`, затем `'3'`
  и так далее до `'9'`
- Два вложенных цикла идут по строкам и столбцам и записывают в каждую клетку следующий символ. Получается поле,
  в котором **каждая клетка подписана своим номером**:

```text
1 2 3
4 5 6
7 8 9
```

## ⁉️ Памятка: метод printBoard

```java
static void printBoard(char[][] board) {
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[i].length; j++) {
            System.out.print(board[i][j] + " ");
        }
        System.out.println();
    }
    System.out.println();
}
```

**Как это работает:**

- Метод ничего не возвращает (`void`) - он только выводит поле на экран
- `board.length` - количество строк, `board[i].length` - количество столбцов в строке `i`
- `System.out.print` выводит символ и **не переходит** на новую строку, поэтому символы одной строки поля стоят рядом
- `System.out.println()` после внутреннего цикла переводит вывод на новую строку - так начинается следующая строка
  поля. Последний `println()` добавляет пустую строку, чтобы поля не слипались

## ⁉️ Памятка: метод makeMove

```java
static boolean makeMove(char[][] board, int cell, char player) {
    int row = (cell - 1) / 3; // row - строка
    int col = (cell - 1) % 3; // col - от анг. column - колонка/столбец

    if (board[row][col] == 'X' || board[row][col] == 'O') {
        return false;
    }

    board[row][col] = player;
    return true;
}
```

**Как это работает:**

- Игрок вводит **номер клетки** от 1 до 9, а в массиве клетка задаётся двумя номерами: строкой и столбцом. Чтобы
  перевести одно в другое, используем целочисленное деление и остаток от деления:

| Номер клетки | `(cell - 1) / 3` - строка | `(cell - 1) % 3` - столбец | Клетка в массиве |
|--------------|---------------------------|----------------------------|------------------|
| 1            | 0                         | 0                          | `board[0][0]`    |
| 2            | 0                         | 1                          | `board[0][1]`    |
| 3            | 0                         | 2                          | `board[0][2]`    |
| 5            | 1                         | 1                          | `board[1][1]`    |
| 7            | 2                         | 0                          | `board[2][0]`    |
| 9            | 2                         | 2                          | `board[2][2]`    |

- Свободная клетка содержит цифру, а занятая - `'X'` или `'O'`. Если в клетке уже стоит один из этих символов,
  метод сразу завершается через `return false` - ход сделать нельзя
- Если клетка свободна, метод записывает в неё символ игрока и возвращает `true` - ход сделан

## ⁉️ Памятка: метод checkWin

```java
static boolean checkWin(char[][] board, char player) {
    for (int i = 0; i < 3; i++) {
        if (board[i][0] == player && board[i][1] == player && board[i][2] == player) {
            return true;
        }
        if (board[0][i] == player && board[1][i] == player && board[2][i] == player) {
            return true;
        }
    }

    if (board[0][0] == player && board[1][1] == player && board[2][2] == player) {
        return true;
    }
    if (board[0][2] == player && board[1][1] == player && board[2][0] == player) {
        return true;
    }

    return false;
}
```

**Как это работает:**

- Выиграть можно на одной из 8 линий. Цикл `for` проверяет сразу 6 из них: когда `i` равно 0, 1 или 2, первое условие
  проверяет **строку** с номером `i`, а второе - **столбец** с номером `i`
- Две диагонали проверяются отдельно, после цикла
- Как только найдена линия из трёх одинаковых символов, метод сразу завершается через `return true` - игрок победил
- Если ни одна линия не подошла, то после всех проверок выполняется `return false` - игрок пока не победил

### Часть 1. Метод readCell

Напиши метод, который спрашивает у игрока номер клетки и **не отпускает его**, пока он не введёт число от 1 до 9.

1. Метод называется `readCell`, получает один параметр - символ игрока (`char`), чей сейчас ход, а возвращает номер
   клетки типа `int`. Он пишется рядом с остальными методами, а не внутри `main`
2. Внутри метода создай `Scanner` для чтения с клавиатуры
3. Объявите переменную `int cell` **до** цикла
4. Создай цикл `do-while`. В теле цикла:
    1. Выведите в консоль, кто ходит, например: `Ходят: X`
    2. Выведите просьбу: `Введите номер клетки от 1 до 9:`
    3. Считайте число с клавиатуры в переменную `cell`
5. Условие цикла `while` должно быть истинным, пока введённое число **неправильное** - меньше 1 или больше 9. Тогда
   вопрос повторится
6. После цикла верни введённый номер клетки через `return cell;`

### Часть 2. Метод main

Для проверки работоспособности всех методов в методе `main` напишите программу для совершения одного хода игроком `X`:

```java
public static void main(String[] args) {
    char[][] board = createBoard();                             // Создание доски
    printBoard(board);                                          // Вывод доски в консоль

    char player = 'X';                                          // Символ игрока, который ходит
    int cell = readCell(player);                                // Выбор клетки игроком

    if (!makeMove(board, cell, player)) {                       // Проверка, что игрок может походить в эту клетку

        System.out.println(player + "пока что не победил!");    // Игрок еще не победил
    }
```

## 🏁 Пример

**Код метода `readCell`**

```java
static int readCell(char player_symbol) {
    Scanner scanner = new Scanner(System.in);
    int cell;
    do {
        System.out.println("Ходят: " + player_symbol);
        System.out.println("Введите номер клетки от 1 до 9:");
        cell = scanner.nextInt();
    } while (cell < 1 || cell > 9);
    return cell;
}
```
